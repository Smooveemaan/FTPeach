Three steps. You’ll mostly repeat the last two.

  1. 1

    Add your server

    Type in the address and your login once and save it. Next time it is one click away. Several servers can stay open at once, each in its own tab.

  2. 2

    Drag files across

    Each pane can show your computer or a server, so copying between two servers is just as easy. Search and sort to find what you need, then drag it over.

  3. 3

    Watch them arrive

    Every file shows up in the queue with its speed and time left. Pause one, cancel another, or set a speed limit. A paused transfer picks up where it stopped.

The little things that make everyday work nicer.

$0

Absolutely free

No trial, no paid edition, no features held back. Every part of FTPeach is free to use, and the code is open under the Apache 2.0 license.

No ads, no account, no tracking

Nothing to sign up for and nothing extra in the installer. FTPeach only goes online to reach your servers and to check GitHub for updates.

Passwords kept safe

Saved passwords are encrypted for your Windows account. Add a master password and unlock it with Windows Hello if you like.

Server to server

Open one server in each pane and copy between them. Files pass through your computer on the way.

Edit in your own editor

Open a file from the server in the app you like, then upload your changes back.

Good-looking, day and night

A calm, modern interface with a light and a dark theme. It follows your Windows setting, or stays the way you set it.

Updates on their own

New versions download in the background and install the next time you start FTPeach. Each one is checked before it installs.

Take it with you

The portable version runs from a folder. Your settings and bookmarks travel with it.

A note before you download

I made FTPeach with a lot of help from AI. I’ve tested it carefully, but please back up files that matter to you. If something feels off, let me know on GitHub.

The download is not code-signed, so Windows may say it protected your PC.
Choose More info, then Run anyway.
