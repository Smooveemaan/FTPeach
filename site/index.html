Drag files to your server and back.

FTPeach is a free FTP, FTPS, SFTP and WebDAV client for Windows. Open your computer or any server in two panes, side by side, then drag files from one to the other.

  • Windows 10 and 11, 64-bit
  • Free and open source, Apache-2.0
Download for Windows View on GitHub {{STARS}}

Three steps. You’ll mostly repeat the last two.

  1. Add your server

    Type in the address and your login once and save it. Next time it is one click away. Several servers can stay open at once, each in its own tab.

  2. Drag files across

    Each pane can show your computer or a server, so copying between two servers is just as easy. Filter the open folder by name or click a column to sort it, then drag the files over.

  3. Watch them arrive

    Every file shows up in the queue with its speed and time left. Pause one, cancel another, or set a speed limit. A paused transfer can continue where it stopped when its source and partial data still match.

What else you get.

Server to server

Open one server in each pane and copy between them. Files pass through your computer on the way.

Passwords kept safe

Saved passwords are encrypted for your Windows account. Add a master password and unlock it with Windows Hello if you like.

Edit in your own editor

Open a file from the server in the app you like, then upload your changes back.

Absolutely free

No trial, no paid edition, no features held back. The code is open under the Apache 2.0 license.

No ads, no account, no tracking

Nothing to sign up for and nothing extra in the installer. FTPeach only goes online to reach your servers and to check GitHub for updates.

Modern and minimal

Two panes with your files, the queue and the log below them. Pick one of 20 color schemes, each in light and dark.

Updates on their own

New versions download in the background and install the next time you start FTPeach. Each one is checked before it installs.

Take it with you

The portable version runs from a folder. Your settings and bookmarks travel with it.
